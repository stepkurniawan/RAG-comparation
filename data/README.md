This folder was my goto folder before I have `experiments` folder. In this folder there are: 
- sustainability methods dumps: literal dumps from https://sustainabilitymethods.org/index.php/Main_Page

- wiki_checklist_segmented: to check which page that I have convert into questions answer and which page are skipped. 

- collection_ground_truth_ragas_chatgpt4: The structured file that contains the complete questions-answers converted from the unstructured Sustainability Wiki dumps. 

- handpicked questions: those questions are taken from hundreds of questions and then we only pick 50 out of it due to financial reasons. 

- chunk split strategies evaluation results: text_splitter and text_overlap

- json2csv.py -> to convert json to csv
